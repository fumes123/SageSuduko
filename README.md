# SageSudoku
**Grow Your Mind, One Puzzle at a Time.**

A garden-inspired Sudoku web application for an HCI 2 project.

## Technologies
HTML5, CSS3, Vanilla JavaScript, and browser LocalStorage.

## Features
- Beginner 4×4, Novice 6×6, and Master 9×9 puzzles
- Random puzzle generation and unique-solution validation
- Interactive board, number pad, notes, undo, erase, hints, and answer checking
- Timer, mistake tracking, and progress indicator
- Light/dark themes and saved game restoration
- Local statistics and responsive layouts
- Custom SVG branding

## Run
Open `index.html` in a modern browser. No backend, server, or package installation is required.

## Storage
Theme, unfinished game, and statistics are stored locally in the browser using LocalStorage. There is no cloud synchronization.

## Structure
- `index.html` — HTML and JavaScript
- `css/style.css` — all CSS
- `assets/images/` — logo and app icon
- `assets/icons/` — favicon
